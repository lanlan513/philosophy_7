# 西方哲学 · 思想档案馆 — 回声标本柜

一张巨大的深色桌面，上面散落着词语标本：自由、灵魂、怀疑、幸福、荒诞、时间、死亡、沉默。
拾起一个词，三位跨时代哲学家的短句、肖像切片与一条细细的年代线会在它周围缓慢浮现。
把词收入自己的小柜子，刷新之后它们仍在。

视觉是旧自然博物馆与前卫杂志的交界：玻璃反光、纸张颗粒、暗红标签、低饱和蓝灰；
没有拟物面板与后台式卡片，内容像收藏品一样散落在留白里。

## 运行

```bash
npm install        # 安装前端依赖（服务端零依赖）
npm run build      # 构建前端到 dist/
npm start          # 启动服务器 → http://localhost:4173
```

开发模式（前端热更新，/api 代理到 4173）：

```bash
npm start          # 终端 1：API 服务器
npm run dev        # 终端 2：Vite 开发服务器
```

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/words` | 词语标本目录（含桌面布局，不含引文） |
| GET | `/api/words/:id/echoes` | 一个词的回声：引文 + 人物 + 出生年（按年代排序） |
| GET | `/api/portraits/:id.svg` | 哲学家肖像切片（服务端确定性生成的 SVG） |
| GET | `/api/cabinet` | 读取我的小柜子（按请求头 `x-echo-uid` 区分访客） |
| PUT | `/api/cabinet` | 保存小柜子 `{ items: [...] }`，服务端校验并持久化到 `server/data-store/` |

调试钩子（任意 `/api` 路径）：`?delay=1500` 模拟慢接口；`?fail=1` 模拟 503 故障。

## 操作

- 鼠标点按 / `Tab` 移动 + `Enter`：拾起或放回一个词
- `← → ↑ ↓`：在标本之间漫游
- `C`：把当前词收入柜子 / 移出
- `Esc`：放回当前词（或关闭柜子）
- 右下角「动效 开/关」：手动切换动效

## 边界情况的处理

| 情况 | 处理 |
| --- | --- |
| 同一词语被连续点击 | 拾起/放回是幂等的状态切换；回声请求在卸载时 abort，过期响应直接丢弃；已取回的回声按词缓存，再拾起零等待 |
| 图像加载失败 | 肖像切片 `onError` 降级为暗红封印 + 姓氏首字；加载中有微光扫过的玻片占位 |
| 字体加载失败 | `FontFace` API 探测 + 3.5s 超时，失败时加 `font-fallback` 类微调字距；字体栈始终回落到系统衬线 |
| 词语没有关联人物 | 「沉默」一词即为空数据：呈现"此词尚未引来回声"与一条"待续"细线 |
| 低性能设备 | `prefers-reduced-motion`、核数/内存过低时默认关闭动效；也可手动开关并持久化；关闭后所有状态即时到位 |
| 接口慢于动画 | 拾起动画不等接口：先立起骨架占位（引文轮廓 + 细线），数据到达后替换；请求带 15s 超时兜底 |
| localStorage 不可写 | 探测后降级为会话内存，收藏改由服务器保存，并以轻提示告知；写入失败不抛错 |
| 移动端 | ≤720px 时散落桌面降级为顺序阅读流：词按目录纵向排列，拾起后回声内联展开，年代线转为相对定位随行 |
| 收藏持久化 | 本地（localStorage/内存）与服务器双写；刷新后先展示本地，再与服务器合并（本地操作优先）；服务器写盘失败时降级为进程内存并在响应中标记 `persisted: false` |

## 结构

```
server/
  index.js       零依赖 HTTP 服务器：API + 静态托管 + 收藏持久化
  data.js        词语、哲学家、引文、桌面布局
  portraits.js   肖像切片 SVG 生成器（确定性）
src/
  App.jsx        编排：目录加载、拾起状态、键盘漫游、柜子、提示
  api.js         轻量请求封装（AbortSignal + 超时 + 访客标识）
  storage.js     localStorage 安全封装（不可写时内存兜底）
  motion.js      动效偏好（系统/设备/手动三级）
  useCabinet.js  收藏状态：本地 + 服务器双写与合并
  components/    Desk / Specimen / EchoField / Timeline / Portrait / CabinetDrawer / Notices
```
