# 思想档案馆 · 回声标本柜

一张可漫游的深色桌面：拾起「自由、灵魂、怀疑、幸福、荒诞、时间、真理、沉默」等词语标本，
周围会缓慢浮现三位跨时代哲学家的短句、肖像切片与一条细细的年代线。
把喜欢的标本收入自己的小柜子，刷新后它们还在。

## 运行

```bash
npm install

# 终端 1：轻量 API（词语 / 引文 / 人物关联 / 收藏读写），默认 :3001
npm run server

# 终端 2：Vite 开发服务器（/api 已代理到 :3001）
npm run dev

# 或生产模式：构建后由同一台服务器托管静态文件与 API
npm run preview   # = vite build && node server/index.js
```

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/words` | 全部词语标本（含桌面坐标） |
| GET | `/api/words/:id/echoes` | 某词的回响：引文 + 人物 + 年代（`?latency=ms` 可模拟慢接口） |
| GET | `/api/cabinet?uid=…` | 读取访客的收藏 |
| PUT | `/api/cabinet` | 保存收藏 `{ uid, items }`，写入 `server/data/collections.json` |

`ARCHIVE_LATENCY` 环境变量可调整接口的基础延迟（默认 120ms）。

## 已处理的边界情况

- **同一词语连续点击**：拾起再放下为切换语义；请求序号守卫保证慢响应不会覆盖新状态。
- **图像 / 字体加载失败**：肖像切片 `onError` 退回排版式占位；字体 4s 未就绪退回系统字体栈。
- **词语无关联人物**：「沉默」返回空回响，界面给出「未著录」空态。
- **低性能设备**：`prefers-reduced-motion`、省流模式、低核数/低内存自动关闭动效，顶栏也可手动开关。
- **接口慢于动画**：拾起动画立即开始，回响位置先出现幽灵占位，数据到达后再填入。
- **localStorage 不可写**：全部读写 try/catch，退回内存态并在状态行提示。
- **移动端**：`≤760px` 时自由散落布局降级为顺序阅读列表，点词展开回响。
